A minimal daily-driver config I am actively using.<br>
The goal is, to not have 20 plugins where half of them you don't even use.<br><br>
It has [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter), [mini.tabline](https://github.com/nvim-mini/mini.tabline), [netrw.nvim](https://github.com/prichrd/netrw.nvim), [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig), [fzf-lua](https://github.com/ibhagwan/fzf-lua) and a [monokai colorscheme](https://github.com/tanvirtin/monokai.nvim) (I am using the Ristretto flavor).<br><br>
**I have LSPs locally set up, so you have to download them manually.** Web searches should help there. In the config tailored for **my** use, hence **this current repository** containing **this config**, LSPs are set up for **Python (basedpyright via pipx), C/C++ (clang via package manager) and Dart (comes with Flutter SDK provided by Google).**<br><br>
_Any additions I will be doing in future, will (hopefully) all be aesthetic. I believe I don't really need anything more than treesitter, fzf and the three LSPs, from a functionality standpoint._<br>
